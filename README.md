# Queue Project

## Deskripsi Project

Project ini adalah sistem Queue yang dibangun menggunakan **Python**. Project ini mendemonstrasikan implementasi Queue data structure dengan antarmuka interaktif menggunakan **Streamlit**.

Website ini memungkinkan Anda untuk:
- Menambahkan (enqueue) elemen ke dalam queue
- Menghapus (dequeue) elemen dari queue
- Melihat antrian (peek)
- Melihat status queue secara real-time
- Memahami cara kerja queue melalui visualisasi interaktif

---

## Prasyarat Sistem

Pastikan sistem Anda memenuhi persyaratan berikut:

### Requirements:
- **Python download dari: [python.org](https://www.python.org/downloads/)**

---

## Install Dependencies


Jalankan perintah berikut untuk menginstall semua package yang diperlukan:

```bash
pip install streamlit
```

---

## Cara Menjalankan Project

### Menjalankan dengan Streamlit

Jalankan command berikut:

```bash
streamlit run app.py
```

**Apa yang terjadi:**
1. Terminal akan menampilkan URL lokal (biasanya `http://localhost:8501`)
2. Browser akan otomatis terbuka dengan website Queue

---

## Menghentikan Website

Untuk menghentikan Streamlit:
**Di Terminal**: Tekan `Ctrl + C`
